# 출석부 (강원온라인학교 출석 관리 앱)

엑셀로 관리하던 공동교육과정 출석부를 대신하는 윈도우 데스크톱 앱입니다.
서버나 로그인 없이 PC 한 대에서 동작하며, 데이터는 `문서\출석부\data.json` 한 파일에 저장됩니다.

## 주요 기능

- **홈**: 오늘 수업 목록(시간 순, 현재 시간대 강조), 회차(차시) 범위, 확정 여부, 이번 주 미리보기, 확인하지 않은 지난 수업, 인정결석 대기 건수
- **출석 입력**: 학생별 `출석 / 결석 / 인정결석(대기) / 인정결석` 선택. 누르지 않으면 출석. 연강은 한 번에 입력하거나 차시별로 나눠 입력. **출결 확인(확정)** 버튼
- **대기 목록**: 공문 미접수 인정결석을 과목 구분 없이 모아 보고, 공문을 확인했으면 체크박스에 체크 → 즉시 인정결석으로 반영. 날짜·소속교 묶음 단위 체크, 사전 등록 항목 단위 체크 가능
- **인정결석 사전 등록**: 소속교 행사(학교 전체)나 공문으로 미리 받은 개별 학생의 결석 기간을 등록하면, 미래 수업을 포함해 기간 안의 수업에서 해당 학생이 인정결석으로 미리 표시됨. 공문 접수 체크 시 바로 인정결석, 아니면 대기
- **날짜·과목 검색**: 기간·과목으로 수업을 찾아 열람·수정
- **출석부 열람·출력**: 과목별 학생 × 차시 행렬, 오늘까지 누적/학기 전체, 인쇄, PDF 저장, **기존 엑셀 양식 그대로 내보내기**
- **설정**
  - 학기 관리(새 학기 시작, 지난 학기 보관·전환), 출석부 출력 양식 업로드(학기별, 서식이 바뀌면 교체), 기존 엑셀 출석부에서 기록 가져오기(이번 학기 한정 이전용)
  - 설정 양식(xlsx) 내려받기 → 작성 → 업로드로 과목·시간표·명단·휴업일·소속교 행사 일괄 반영
  - 과목·주간 시간표, 수강생 명단(수강취소일), 휴업일, 보강, 과목별 휴강, 인정결석 사전 등록
  - 데이터 폴더 변경, 백업/복원, 전체 초기화, 윈도우 시작 시 자동 실행

## 규칙

- 회차 번호는 실제 수업일 순서로 자동 계산됩니다. 휴업일은 번호를 차지하지 않습니다.
- 확정하지 않은 수업은 출석부에 빈칸으로 남고 홈 화면에 경고로 표시됩니다.
- 엑셀 내보내기: 출석 `O`, 인정결석 `◎`(공문 대기는 노란 칸), 미인정결석 `X`. 미확정 수업일은 날짜 칸이 붉게 표시됩니다.
- 앱을 켤 때마다 하루 한 번 `backups/` 폴더에 자동 백업하고 최근 30개를 보관합니다. 가져오기·초기화·복원 전에도 백업합니다.

## 개발

```bash
cd attendance
npm install
npm test            # 핵심 로직·엑셀 입출력 단위 테스트
npm run test:e2e    # Electron 전체 흐름 (리눅스에서는 xvfb-run -a npm run test:e2e)
npm start           # 앱 실행
npm run dist:win    # 윈도우 설치형 + 무설치형 exe (dist/)
```

- `src/core/`: 순수 로직 (날짜, 모델, 시간표 엔진, 출결, 엑셀 가져오기·내보내기, 설정 양식)
- `src/main/`: Electron 메인 프로세스 (데이터 파일, 백업, 대화상자, IPC)
- `src/renderer/`: 화면 (의존성 없는 순수 HTML/CSS/JS)
- `resources/template.xlsx`: 기본 출석부 출력 양식. 설정에서 학기별 양식을 업로드하면 `데이터폴더/양식/`에 저장되어 그것을 씁니다. 내보내기는 양식 시트의 구조("연번", "이름", "n차시" 제목 위치, 표 간격, 학생 행 수, 비고 칸)를 자동으로 읽습니다.

환경변수 `ATTENDANCE_DATA_DIR`로 데이터 폴더를 바꿀 수 있습니다(테스트용).

## 배포

GitHub Actions(`.github/workflows/attendance-build.yml`)가 윈도우에서 빌드합니다.

- `attendance-v0.1.0` 같은 태그를 푸시하면 테스트 → 빌드 → Release에 exe 두 개를 올립니다.
- Actions 탭에서 수동 실행(workflow_dispatch)도 가능합니다.

서명되지 않은 실행 파일이므로 처음 실행 시 SmartScreen 경고가 뜹니다. "추가 정보 → 실행"을 누르면 됩니다.
